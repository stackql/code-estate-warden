# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security reports. A public issue discloses the problem before a fix is available.

Report privately with GitHub private vulnerability reporting: open the Security tab of this repository, choose Advisories, then "Report a vulnerability". Include the affected version, steps to reproduce, and the impact you expect.

If private vulnerability reporting is not available on this repository, contact the maintainers of the {{org}} organization through the security contact on the organization profile.

## Supported Versions

Security fixes are applied to the latest release. Older releases are supported on a best-effort basis; please upgrade to the latest release where you can.

## Response

We aim to acknowledge a report within a few business days, keep you informed while we investigate, and coordinate the disclosure timing with you once a fix or mitigation is ready. We follow coordinated disclosure and credit reporters in the advisory unless they prefer to remain anonymous.
